# Free-plan limits and scope

Documentation checked 2026-10-25; actual Free-account UI/workflow test is pending. Features can vary by account, region, client and limits. The kit requires manual initiation, not automation.

| Component | Documentary position | Our proof status |
|---|---|---|
| Ordinary chat/instructions | Available, tool quotas apply | Codex behavior is a separate test |
| Projects | Free support; 5 files/project | Free UI and instructions not tested |
| Uploads | PDF/TXT and other documents on Free; 3 uploads/day, possibly reduced at peak | No Free upload completed |
| Search | Available subject to allowance/access | Manual provided-source path used for controlled tests |
| New personal custom GPT | Creation unavailable per current guidance | Not part of this kit |
| Agent mode | Paid | Not part of this kit |
| Tasks | Eligible Free has limited scheduled tasks; context/feature restrictions apply | Not used or required |

Sources: [Free FAQ](https://help.openai.com/en/articles/9275245-chatgpt-free-tier-faq), [Projects](https://help.openai.com/en/articles/10169521-projects-in-chatgpt), [uploads](https://help.openai.com/en/articles/8555545-uploading-files-and-audio-to-chatgpt), [GPT creation](https://help.openai.com/en/articles/8554397-creating-and-editing-gpts), [agent mode](https://help.openai.com/en/articles/11752874-chatgpt-agent), [Tasks](https://help.openai.com/en/articles/10291617-scheduled-tasks-in-chatgpt).

Instructions cannot guarantee correct citations, perfect memory, security against every malicious source or persistent autonomous behavior. A real Free run must check access, responses, uploads and a fresh Project chat separately. A paid/Codex test does not fill those gaps.
