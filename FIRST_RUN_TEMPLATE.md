# First-run template

In an ordinary new chat, first paste the finished instructions, then the source text and this input. If you use an optional configured Project, start a chat inside it and confirm which source file is actually available/read.

```text
Task: [WHAT I NEED]
Required result: [DELIVERABLE]
Mandatory requirements: [HARD CONDITIONS]
Preferences: [NICE TO HAVE]
Input materials: [FILENAMES / TEXT]
Allowed source IDs for this run: [IDS]
Source date/version: [DATE + PACK VERSION]
Available tools: [ACTUALLY CONFIRMED TOOLS; OR PROVIDED TEXT ONLY]
Actions authorized: analysis and drafting only.

Use the current instructions and the allowed source set. Report what you can confirm, what fails a requirement and what remains unknown. Cite the decisive evidence and give one next step. Do not claim to have executed a downstream task unless you actually did.
```
