# Rights and evidence boundary

This package contains original prompts, templates, teaching fixtures, curated source summaries and genuine sanitized Codex inputs/final responses. Third-party documentation is linked, not copied in full. No Morty article artwork or video is included.

Source-pack statements are dated summaries, not licensed vendor guarantees. Fictional lesson cards and hypothetical file specifications are explicitly labeled. Generated instructions are distinguished from production-agent reference templates.

Curated evidence excludes account identity, browser/session material, private screenshots, authentication data, CLI paths/thread identifiers and reasoning events. Do not upload the entire evidence directory or evaluator answers into the assistant you are testing. Read the relevant input and output separately.
